DB Port Notes

- Default MySQL port for this project is 5001 (configurable).
- Environment variables:
  - MYSQL_USER
  - MYSQL_PASSWORD
  - MYSQL_HOST (default: 127.0.0.1)
  - MYSQL_PORT (default: 5001)
  - MYSQL_DB (default: sales_inventory_db)
- Alternatively set DATABASE_URL to override individual values.
